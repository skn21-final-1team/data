# IR 평가 지표 설명

## 평가 목적

Retriever가 질문에 대해 관련 문서를 얼마나 잘 찾아오는지 측정한다.
LLM 호출 없이 키워드 매칭 기반으로 관련성을 판정한다.

## 관련성 판정 방식

ground_truth에서 핵심 키워드를 추출하고, 검색된 청크에 해당 키워드가 40% 이상 포함되면 "관련"으로 판정한다.

- 불용어(조사, 관사 등) 제거 후 키워드 추출
- `키워드 매칭 수 / 전체 키워드 수 >= 0.4` 이면 관련

## 지표

| 지표 | 설명 | 범위 | 좋은 값 |
|---|---|---|---|
| Hit Rate | 관련 문서를 1개라도 찾았는가 | 0~1 | 1.0 |
| MRR | 첫 번째 관련 문서의 순위 역수 (1위=1.0, 2위=0.5, ...) | 0~1 | 1.0 |
| NDCG | 관련 문서가 상위에 몰려있을수록 높음 (순위 품질) | 0~1 | 1.0 |
| Precision@K | 상위 K건 중 관련 문서 비율 | 0~1 | 높을수록 |
| Recall@K | K건 내에서 관련 문서를 얼마나 찾았는가 | 0~1 | 높을수록 |

## 예시

질문: "Tesla는 언제 설립되었나요?" (top_k=5)

| 순위 | 청크 내용 | 관련? |
|---|---|---|
| 1 | "전기차 배터리 기술..." | X |
| 2 | "Tesla는 2003년 7월 설립..." | O |
| 3 | "주가 변동..." | X |
| 4 | "Tesla Motors에서 사명 변경..." | O |
| 5 | "자율주행 기술..." | X |

| 지표 | 계산 | 결과 |
|---|---|---|
| Hit Rate | 관련 문서 존재 → 1 | 1.0 |
| MRR | 첫 관련 = 2위 → 1/2 | 0.5 |
| NDCG | 2,4위에 관련 문서 | 0.77 |
| Precision@5 | 2/5 | 0.4 |
| Recall@5 | 2/5 | 0.4 |
